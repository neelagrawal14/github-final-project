# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a simple project that calculates the interest earned or paid on a principal amount over a specified period at a fixed annual interest rate.

## Purpose

This project helps users calculate simple interest quickly and accurately using three inputs: principal amount, annual rate of interest, and time period.

## Formula

Simple Interest is calculated using the formula:

**Simple Interest = (Principal × Rate × Time) / 100**

Total Amount = Principal + Simple Interest

Where:
- **Principal:** The initial amount of money.
- **Rate:** The annual interest rate in percentage.
- **Time:** The time period in years.

## Example

Suppose:
- Principal = 1000
- Rate = 5% per year
- Time = 2 years

Calculation:

Simple Interest = (1000 × 5 × 2) / 100 = 100

Total Amount = 1000 + 100 = 1100

## How It Works

1. Enter the principal amount.
2. Enter the annual rate of interest.
3. Enter the time period in years.
4. Calculate the simple interest using the formula.
5. Add the interest to the principal to obtain the total amount.

## Technology

This project can be implemented using a Bash shell script.
